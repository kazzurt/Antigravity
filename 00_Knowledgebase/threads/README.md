## Thread scorecard

Use ordinal ratings with written justification for:

- explanatory coverage;
- compatibility with established constraints;
- new-physics burden;
- evidence adjacency;
- proxy testability;
- engineering continuity;
- cross-source convergence;
- falsifiability.

Scores rank attention; they are not probabilities that a theory is true.
