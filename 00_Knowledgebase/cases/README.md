# UAP Case and Release Register

Case pages translate observations into candidate capabilities while keeping direct observations separate from inference.

## Admission schema

Each page records:

- source and chain of custody;
- direct observations versus witness or analyst interpretation;
- available and missing sensor metadata;
- candidate capability implications;
- strongest conventional alternatives;
- decisive missing evidence;
- relationship to the assumption ladder.
