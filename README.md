# Antigravity

Antigravity is a requirements-first research program investigating whether an
engineered, low-tidal local inertial frame—or protected worldtube—can be made
physically coherent while preserving source, stress-energy, and momentum
bookkeeping.

The project operates in discovery and audit modes simultaneously. Candidate
mechanisms are explored under the working premise, but source provenance, null
results, scaling failures, conservation constraints, and explicit stop
conditions remain part of every evaluation.

## Repository scope

This public repository contains analyses of publicly available papers and
records: the knowledgebase, synthesis reports, idea-stage work, and
reproducible calculations.

Third-party papers themselves, experimental and engineering work, and private
material are not part of this repository. Source digests retain bibliographic
and provenance information for the papers analysed.

No claim is made that a gravity-control mechanism has been demonstrated.
